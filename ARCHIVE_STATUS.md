# Public archive status

This is the editorially cleaned independent draft with a public-safe provenance subset. It is not a camera-ready submission or a fully reproducible experiment package.

The accepted/submitted lineage is retained through source_recovery/. The complete accepted baseline and provenance freeze remain preserved in the separate local archive; their Git branches and bundled history are not published here.

Exact end-to-end reproducibility is not claimed. Original graph realizations and definitive notebook execution state are unavailable; candidate construction versions conflict and the Figure4 tabular discrepancy remains unresolved.

A stronger publication requires a new clean, versioned experiment ensemble with saved raw graphs, explicit sampling/edge rules, software state, replication, and suitable spatial controls and baselines. No new experiments or manuscript/figure computations were run during this publication pass.

Public-safety changes are documented in PUBLIC_SAFETY_AUDIT.md and PUBLIC_OMISSIONS.md. The published Git history contains only the existing GitHub README history plus the audited snapshot; it excludes the local migration/archive commit and all exploratory history.

# Public archive omissions

The complete local archive is retained separately and is not uploaded. The public computational_provenance_frozen directory is an explicitly curated subset, not the complete frozen archive. Original historical files were not edited.

## Reasons

- Review-change ledger and review/revision planning material: excluded to avoid publishing confidential review content or reviewer-derived correspondence records.
- All Git bundles, Git evidence/reflogs, unreachable objects and repository ZIPs: excluded so exploratory history cannot be distributed as embedded archives.
- Full exploratory notebook and full notebook-input dump: replaced by selected indexed evidence cells relevant to the retained claims.
- Later/duplicate snapshots and unrelated black-hole, hyperbolic and graph-curvature benchmark outputs: excluded from the narrow manuscript package.
- Local search inventories, absolute-path maps, build logs, obsolete validation snapshots and patch files: omitted as unnecessary local/recovery artifacts.
- Duplicate original accepted PDF in reference/: source_recovery/compiled_baseline.pdf and the recovered source/assets retain the baseline lineage.
- Machine-specific source path fields were replaced by basenames; documentation/build paths are now repository-relative. Original local hashes for sanitized records do not describe the public derivatives.

Some historical claim/audit documents name omitted evidence (especially the full notebook and old reports). Those references describe the local audit chain, not a claim that every historical input is publicly included. Selected notebook cells preserve their original index numbers; missing indices are intentional, not proof of missing original analysis. This release does not improve the underlying reproducibility classification.
